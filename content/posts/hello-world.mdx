## How posts are written

Every post is a `.mdx` file in `content/posts/`. The top of the file holds the metadata:

```yaml
---
title: "My post title"
description: "One sentence shown in lists and search results."
date: 2026-10-01
tags: [backend, notes]
draft: true # hidden in production builds until you flip it
---
```

Everything below that is regular Markdown, with code highlighting:

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`;
}
```
